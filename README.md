# niyyahly Product Analytics

## Reducing onboarding friction while preserving personalisation 

niyyahly is a Muslim-tailored reflection and journaling product that use MBTI and other personalisation inputs.

This project explores how onboarding friction may effect activation, engagement and retention.

## Product Analytics Question

Does reducing the effort required to establish personalisation help users reach the core reflection experience without reducing downstream engagement?

## Synthetics Data Disclosure

All behavioural data in this project is synthetics and created for portfolio and educational purposes.

It does not represent real niyyahly users and must not be interpreted as evidence about real customer behaviour or mental-health outcomes.

# NiyyahLy Activation Analysis

## Product Question

After completing onboarding, do users reach NiyyahLy's core reflection experience?

## Why Activation Matters

Onboarding completion alone does not demonstrate that a user has experienced the product's core value.

This analysis examines whether users who begin the NiyyahLy journey progress from onboarding into the core reflection experience.

---

## Activation Definition

For this portfolio, a user is considered activated when they complete the following journey within 24 hours of signup:

1. Onboarding completed
2. Mood selected
3. Topic selected
4. Tone selected
5. Prompt generation completed
6. Journal saved

The activation event is therefore:

> `signup_completed → onboarding_completed → mood_selected → topic_selected → tone_selected → prompt_generation_completed → journal_saved`

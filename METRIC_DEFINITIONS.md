# NiyyahLy Metric Definitions

Onboarding completion = completed onboarding / started onboarding.
Median onboarding duration = median onboarding_started → onboarding_completed.
Activation = mood + topic + tone + successful prompt generation + journal save within 24 hours of signup.
D1/D7/D30 meaningful retention = eligible cohort users with journal_saved on target day / eligible cohort users.
Journal save rate = journal savers / successful prompt users.
Regeneration rate = users regenerating / successful prompt users.
Journal depth: short <50 words; medium 50–149; deep 150+.
Reflection days 30 = distinct journal_saved calendar days in first 30 days.
Notification tap rate = tapped delivered notifications / delivered notifications.
Inspire save rate = Inspire savers / Inspire viewers.
WMJU = 7-day unique users completing check-in + prompt generation + journal save.
Experiment primary metric = D7 meaningful journaling retention.
Guardrails = AI failure/latency, notification failure/opt-out, safety aggregates and downstream engagement.

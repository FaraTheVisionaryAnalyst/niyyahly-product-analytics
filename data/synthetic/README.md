# NiyyahLy Synthetic Data

This directory contains synthetic data created specifically for the NiyyahLy Product Analytics portfolio.

No real NiyyahLy customer data is used.

The dataset is designed to simulate product behavior across:

- onboarding
- MBTI personalization
- mood and reflection
- AI prompt generation
- journaling
- Inspire
- notifications
- programmes
- Community
- experimentation

The data will be loaded into BigQuery for analysis and visualized in Tableau.
